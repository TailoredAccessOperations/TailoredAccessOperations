### ⚡ Fun Fact
Did you know that the first computer virus ever created was called the "Creeper virus" in the early 1970s? It wasn’t malicious—it just displayed the message “I’m the creeper, catch me if you can!” It was actually more of a prank than a real threat. The first antivirus software was created to catch it, and it was called the "Reaper." So, in a way, antivirus software was invented just to catch the world’s first computer prankster!
